## 📌 Executive Summary
**HostelSetu** is an offline-first, verified student housing discovery and safety enforcement platform tailored for Indian educational hubs (specifically Knowledge Park, Greater Noida). It disintermediates illegal broker networks through a **₹999/month B2B SaaS model** for PG landlords while guaranteeing resident safety through a **6-point physical safety audit** and a **100-point dynamic Trust Score algorithm**.

---

## 🎯 The Core Problem
In Greater Noida alone, over **1,50,000 students** search for private accommodations every year:
1. **The Broker Trap**: Students pay ₹5,000 to ₹10,000 in non-refundable broker cuts for unverified rooms.
2. **Safety Deficit**: Zero accountability for electrical short circuits, bare wires, fire safety, and mess hygiene.
3. **Fake Online Listings**: Generic classifieds (99acres, MagicBricks) permit unverified self-listings with misleading photos.

---

## 🛡️ The 6-Point Physical Safety Audit Standard
Every hostel listed on HostelSetu must undergo an in-person physical inspection across:
1. **CCTV Gate Surveillance & Biometric Entry**: 24/7 entry cameras and mandatory visitor logbook.
2. **Fire Safety Extinguishers & Emergency Exits**: Certified pressure gauges and unblocked staircases.
3. **Food Mess Hygiene & Commercial RO Water**: Tested kitchen cleanliness and drinking water TDS < 120.
4. **Electrical Safety & MCB Load Breakers**: Dedicated floor circuit breakers, zero bare-wire *jugaad*.
5. **Staff Police Verification & Warden Register**: Verified background checks for guards and wardens.
6. **Zero Hidden Electricity Surcharges**: Transparent commercial sub-meter billing.

---

## 🧮 The 100-Point Dynamic Trust Score Formula
$$\text{Trust Score} = (40\% \times \text{Audit}) + (30\% \times \text{Reviews}) + (20\% \times \text{Temporal Decay}) + (10\% \times \text{Grievance SLA})$$

* Toggling any critical safety checkpoint to **FAIL** automatically plunges the property score below 70, triggering an instant warning badge.

## 💻 Tech Stack (100% Native — Zero External Dependencies)
* **Frontend**: Pure Semantic HTML5, Custom Responsive CSS3 Design Tokens, Vanilla JavaScript (ES6+).
* **Backend**: Object-Oriented PHP 8.2 with PDO (Prepared Statements for SQL Injection Immunity).
* **Database**: MySQL 8.0 / InnoDB Relational Database with cascading foreign keys.
* **Architecture**: Multi-Page Architecture (MPA) with zero external CDNs, 100% offline compliant.

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Piyush-Thakur7/hostelsetu.git
   ```
2. Place in web root (e.g. `C:\xampp\htdocs\hostelsetu`).
3. Import `database/schema.sql` into MySQL / phpMyAdmin.
4. Open browser at `http://localhost/hostelsetu/` or `http://localhost:8000/`.
